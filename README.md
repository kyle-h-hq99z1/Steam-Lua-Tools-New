## 🎮 What is This?

**Steam-Lua-Tools** is a complete Lua script management and manifest tool for Steam. It allows you to easily view, install, remove, and manage Lua scripts and manifests for your Steam games .

Built with **Millennium** integration and supporting tools like **ACCELA** and **SLSsteam**, it centralizes common Lua modding tasks: detect games, add or remove Lua scripts, apply fixes, check available APIs, and keep the plugin up to date .

## 🎯 Usage

### Basic Usage
1. Launch Steam with Millennium
2. Open the LuaTools interface in Steam
3. Select a game (or use its AppID)
4. Add/remove Lua scripts or apply available fixes
5. Review logs/status to verify each action

### ⚡ Quick Commands

**Add Script:**
```lua
addappid(1361510) -- Unlock game with AppID 1361510
```

**Add Token:**
```lua
addtoken(1361510, "2764735786934684318") -- Add access token
```

**Set Manifest:**
```lua
setManifestid(1361511, "5656605350306673283") -- Set manifest ID
```

**Online Fix:**
Add `-onlinefix` to Steam launch parameters to enable online multiplayer for supported games
